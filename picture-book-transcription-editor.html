🗂️
Image Transcription Editor
Transcribe text from historical images and mark regions of interest.
Everything is tracked in a RO-Crate file saved automatically in your project folder.
1 · Open your folder — Click Open Folder and select the folder with your image or PDF files. PDFs are split into one image per page automatically. The tool creates a RO-Crate file in the folder to track all your work. If one already exists, your previous work is loaded instantly and you can resume where you left off.
2 · Transcribe text — Type the text you see in the image into the box on the right. Up to three languages per image using the tabs. Use Notes for uncertain readings. Navigate with ◀ Prev / Next ▶ or the arrow keys.
3 · Select regions — Click ⬚ Select Region, then drag a rectangle over any area you want to extract — a stamp, seal, drawing. The crop is saved to your folder immediately. Click ✕ on a region tag to delete it and remove the file. Press Esc to exit drawing mode.
4 · Export crops — Click ⬇ Download Crops to get a ZIP of all your region crops as individual JPEGs. Open and edit them in Paint.NET or any image editor. Do not rename the files.
5 · Import edited crops — After editing, click ⬆ Import Crops and select the folder containing your edited files. They are matched automatically, copied into your project folder, and recorded in the metadata. Region tags show ✓ edited in green.
📦 Native RO-Crate — This project is Native RO-Crate: all metadata lives in a single open-standard file (ro-crate-metadata.json) directly in your folder. It records every image, transcription, region and crop with full provenance. The file can be read by any RO-Crate compatible tool and shared or archived as-is alongside your images.
💾 Automatic saving — The RO-Crate file is created and kept up to date as you work — on navigation, region changes, and after a short typing pause. Press Ctrl+S or click 💾 Save to force an immediate update.
⚠️ Browser requirement — Requires Google Chrome or Microsoft Edge (version 86+) to read and write files. Firefox and Safari can edit but cannot save directly. Internet is only needed the first time a PDF is processed.

📖 How to use this tool

1
📂
Open your folder
Click Open Folder and select the folder with your JPEG, PNG or PDF files. PDFs are split into one image per page automatically. The tool creates a RO-Crate file in the folder to track all your work. If one already exists, your previous work resumes instantly.
2
✍️
Transcribe text
Type a Language code (e.g. eng, fra, tok) — it applies to all images. Type the visible text into the large box. Up to three languages per image using the tabs. Use Notes for uncertain readings. Press ←→ arrow keys or ◀ Prev / Next ▶ to navigate.
3
📐
Select regions
Click ⬚ Select Region (cursor becomes crosshair). Drag a rectangle over any area to extract it — stamps, seals, drawings. The crop is saved to your folder immediately. Click a region tag to highlight it; click ✕ to delete it and remove the file. Press Esc to exit drawing mode.
4
⬇️
Export crops
Click ⬇ Download Crops to get a flat ZIP of all region crops as JPEGs. Open in Paint.NET or any editor. Do not rename the files — the unique ID in each filename is how they get matched when you re-import.
5
⬆️
Import edited crops
After editing, save the files into one folder (keep names unchanged). Click ⬆ Import Crops and select that folder. Files are matched by ID, copied into your project, and recorded in the metadata. Region tags turn green and show ✓ edited.
6

Native RO-Crate
This project is Native RO-Crate — all metadata lives in a single open-standard file (ro-crate-metadata.json) directly in your folder. It records every image, transcription, region and crop with full provenance. The file can be read by any RO-Crate compatible tool and shared or archived as-is alongside your images.
